# Section 6
Amendment of a code
6.—(1) Where the Majlis Adat Istiadat Sarawak is satisfied that—
(a) there has been an error in any code or in the translated version thereof; or
(b) there has been an inadvertent omission of any recognized custom in any code; or
(c) after consultation with the Chiefs and Headmen of the native community concerned, any custom contained in a code should no longer be practised or is obsolete,
it may, with the approval of the Majlis Mesyuarat Kerajaan Negeri, by order published in the Gazette, either rectify the error or include any custom that has been omitted or delete any custom in any code which is to be abolished or is declared to be obsolete.
(2) Save as aforesaid, no amendment shall be made to any code.
